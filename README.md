# Swiggy Sales & Business Analysis Dashboard

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze Swiggy sales and business data.

The dashboard provides insights into sales performance, customer behavior, restaurant performance, and other important business metrics.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## 📌 Key Analysis

- Total Sales
- Total Orders
- Average Order Value
- Restaurant Performance
- Customer Analysis
- Sales Trends
- Category Analysis
- Location-wise Performance

## 📈 Dashboard

The dashboard was created using Microsoft Power BI with interactive charts, KPIs, filters and slicers.

## 📁 Files

- `Swiggy.pbix` — Power BI project file
- `README.md` — Project documentation

## 🚀 How to Use

1. Download the `Swiggy.pbix` file.
2. Open it using Microsoft Power BI Desktop.
3. Refresh the data if required.
4. Explore the interactive dashboard.
